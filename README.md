# mdflow

**Remove the website. Preserve the document.**

mdflow is a deterministic, faithful reading layer for technical web content. Give it a URL and
get the document — not the website around it — as clean, canonical Markdown, backed by a typed
document model that agents and pipelines can consume without hallucination.

The unit is the document, not the page: a documentation section becomes one coherent, navigable
document. The transformation is deterministic and auditable — same source, same output, and
anything it cannot represent is marked, never silently dropped.

## Status

Early. Phase 0: validating the extraction approach against real technical content before building
the product.
