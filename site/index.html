why

A summarizing fetch returns a model's paraphrase of the page and says nothing about what it left out. bareflow keeps the page's own words and lists each part it could not keep.

Claude Code's WebFetch on deno add (457 bytes) ends:

This flag strips the scope prefix, allowing you to import the package using only its base name rather than the full scoped identifier.

The Deno docs end:

Packages given an explicit alias are unaffected.
