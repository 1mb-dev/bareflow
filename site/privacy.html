bareflow

privacy

  • bareflow logs neither the address you convert nor you; it counts only how each fetch ended (ok, or the error's name) and the site's status class, such as 4xx. The site you name gets the request from Cloudflare, not from your IP; a Cloudflare header names the domain it came through.
  • Cloudflare hosts this site and sees each request, the address included. Cloudflare privacy policy
  • Converting an address runs Cloudflare Turnstile, which reads your IP and browser to tell a person from a bot; bareflow sends Cloudflare your IP to confirm the result. Turnstile privacy addendum
  • A pasted page stays in your browser: no Turnstile, no fetch.
  • bareflow sets no cookies. Your browser keeps two settings: the theme and "more" or "less".
  • "report wrong output" opens GitHub with the address and the copy's header in the link; the issue is posted only if you submit it.
